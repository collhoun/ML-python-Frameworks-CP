# Происхождение данных RuReviews

## Название и назначение

**RuReviews** — автоматически размеченный датасет отзывов о товарах на русском языке для задачи анализа тональности. В проекте используется для EDA и последующего сравнения влияния обогащения данных на качество и устойчивость моделей.

Официальный репозиторий: [https://github.com/sismetanin/rureviews](https://github.com/sismetanin/rureviews).

Согласно README источника, отзывы собраны по top-ranked товарам одной категории — «Women’s Clothes and Accessories» — на крупном e-commerce сайте. Исходные пользовательские оценки были автоматически преобразованы в классы тональности; полный набор, заявленный в README, содержит 821 000 отзывов.

## Формат файла

Файл имеет расширение `.csv`, но фактически разделён табами; при этом он не является строгим TSV. Внутри текстов есть неэкранированные переводы строк и табуляция, поэтому наивное чтение через `pandas.read_csv(sep="\t")` не используется. В ноутбуке применяется проверенный парсер: физические строки накапливаются до строки, последнее поле которой после последнего таба равно одной из известных меток.

| Показатель | Значение |
|---|---:|
| Логических записей | 90 000 |
| Физических строк | 101 893 |
| Записей, занимающих более одной физической строки | 4 661 |
| Записей с табуляцией внутри текста | 4 |
| Переводы строк CRLF | 8 452 |
| Байты LF | 98 453 (включая LF в составе CRLF) |
| Одиночные CR | 3 440 |
| Символы `U+0085` (NEL) | 14 |
| BOM | нет |
| `U+FFFD` | 0 |

Символы `U+0085` не считаются разделителями физических строк и сохраняются в текстах. Они входят в 19 mojibake-строк, описанных ниже. После разбора добавлены поля `sentiment_raw`, `line_start`, `line_end`, `n_physical_lines`, а `sentiment` нормализован; в DataFrame на этапе загрузки — 6 столбцов.

## Схема полей

| Поле | Тип после загрузки | Происхождение | Подтверждённое содержимое |
|---|---|---|---|
| `review` | `string` | Исходный столбец | Текст отзыва; 90 000 непустых значений, 87 321 уникальный текст |
| `sentiment_raw` | `string` | Исходный столбец | `negative`, `neautral`, `positive`; по 30 000 записей |
| `sentiment` | `category` | Производное | `negative`, `neutral`, `positive`; по 30 000 записей |
| `line_start` | целочисленный | Диагностическое | Начальная физическая строка записи |
| `line_end` | целочисленный | Диагностическое | Конечная физическая строка записи |
| `n_physical_lines` | целочисленный | Диагностическое | Число физических строк записи |

В исходном файле ровно два столбца: `review` и `sentiment`. Поле `sentiment_raw` и диагностические поля создаются парсером; `sentiment` — нормализованная версия исходного столбца. Эти производные поля не публикуются как исходные данные.

## Целевая переменная и метки

Целевая переменная — `sentiment` с тремя классами:

| Класс | Количество | Доля |
|---|---:|---:|
| negative | 30 000 | 33.33 % |
| neutral | 30 000 | 33.33 % |
| positive | 30 000 | 33.33 % |

Метки в файле: `negative`, `neautral`, `positive`. `neautral` — опечатка в исходном файле; в анализе она нормализуется в `neutral` только в памяти, а исходное значение сохраняется в `sentiment_raw`.

По README источника метки получены из пользовательских оценок по 5-балльной шкале и затем сжаты в 3 класса. Формулировка README противоречива: оценки «1» и «2» отнесены к negative, а «3» и «5» буквально — к positive, хотя заявлены три класса, включая neutral; оценка «4» не упомянута. Поэтому точное соответствие оценок 3/4/5 классам — **Требует проверки**; в EDA это правило не используется как доказанный факт.

Balanced-файл содержит по 30 000 записей на класс. По README это результат undersampling’а; доли классов не отражают естественное распределение.

## Исходные разбиения и метаданные

- Исходных train/validation/test-разбиений в файле нет.
- Нет рейтинга, категории, даты, идентификатора товара или пользователя; доступны только текст и метка.
- Полный набор на 821 000 отзывов в проверенном master-репозитории не опубликован; в EDA он не использовался.
- Сведения о дате сбора отзывов и географии авторов в файле отсутствуют.

## Качество данных

| Показатель | Значение |
|---|---:|
| Пропуски `NaN` в `review` / `sentiment_raw` | 0 / 0 |
| Точные пустые тексты | 0 |
| Тексты только из пробелов | 1 |
| Строки с C1/управляющими символами | 19 |
| Восстановимый mojibake | 19 строк; 662 C1-символа |
| `U+0085` (NEL) | 14 символов |
| NBSP/zero-width | 72 строки |
| HTML-подобные фрагменты | 1 |
| URL | 128 |
| Строки с цифрами | 31 874 |
| Строки с латиницей | 14 479 |
| Строки без кириллицы | 1 262 |
| Строки без кириллицы вне mojibake | 1 243 |
| Тексты короче 10 символов | 1 451 |
| Тексты короче 3 символов | 187 |
| Текст, целиком равный `-` | 13 |

19 строк с C1-символами являются mojibake: UTF-8-байты кириллицы были ошибочно прочитаны как Latin-1. Все 19 строк восстанавливаются обратным преобразованием `latin-1 → UTF-8` и после восстановления содержат кириллицу. В EDA они не исправлялись, чтобы не изменять исходные тексты.

Единственный текст только из пробелов не является `NaN`, но не содержит содержательного отзыва. Специальные маркеры `nan`, `none`, `null`, `n/a` в точном виде не встречаются.

## Ограничения и открытые вопросы

| Вопрос | Статус |
|---|---|
| Точная дата и способ получения локальной копии | Не установлено |
| Точное соответствие оценок 3/4/5 классам | Требует проверки по статье или исходным данным |
| Естественное распределение классов | Не установлено; balanced-файл для этого не подходит |
| Доступность полного набора на 821 000 отзывов | В проверенном master-репозитории не опубликован |
| Корректность автоматической разметки и доля ошибок | Требует ручной проверки |
| Наличие персональных данных | Отдельный PII-аудит не проводился |
| Язык отзывов без кириллицы | Языковой детектор не применялся |

Результаты EDA относятся к опубликованному balanced-файлу и не переносятся автоматически на другие домены, периоды или естественное распределение классов.
